## ✨ 项目简介

**Peirato's Piano** 提供可以自由切换的完整瀑布流窗口和桌面迷你键盘。启动后即可自由演奏，浮动菜单会在弹下第一个音时自动收起；音条从琴键向上升起，实色部分表示按键时长，浅色尾迹表示踏板延音。

主窗口可以切换自由演奏、MIDI 播放和跟弹练习：自由演奏向上生成音条，播放／跟弹向下显示曲目音符。曲库、导入、进度和练习控制都在主窗口内完成。自由演奏支持录制、草稿试听和 MIDI 保存，保存后可直接加入曲库。

它适合这些场景：

- 外接 MIDI 键盘时，作为桌面可视化键盘使用；
- 没有 MIDI 键盘时，直接用电脑打字键盘或鼠标演奏；
- 加载 MIDI 文件后，进行预览播放、区间播放和左右手跟弹练习；
- 使用自定义 SF2 音源，让本地软件音色更贴近自己的偏好；
- 作为直播、录屏、教学或练琴时的键盘提示组件。

## 🚀 功能特性

### 🎹 桌面钢琴键盘

- 完整瀑布流 / 简单键盘在同一个窗口内切换，分别记住窗口尺寸；
- 简单键盘仅用于自由演奏，隐藏录制；播放和跟弹使用完整瀑布流窗口；
- 拖动琴键上沿调整高度，按窗口比例记忆；双击分隔条恢复自动高度；
- 自由演奏音条从下向上移动，和琴键共用坐标，缩放与切换键数保持对齐；
- 顶部浮动菜单与钢琴常用设置，首音自动收起菜单，编辑控件时不会误触电脑琴键；
- 主窗口选择、滑块与开关使用 Naive UI，界面强调色随完整设置中的按键主题同步，背景保持中性灰；
- 轻量长条状键盘界面，适合悬浮在桌面、直播画面或教学录屏中；
- 支持白键 / 黑键实时高亮，按下、松开、延音状态都能同步反馈；
- 支持和弦名称识别，显示中英文名称、别名及实时按键音名（含八度）；
- 和弦面板宽度随内容调整，保持两行布局；短暂保留完整和弦，减少分散按下、抬指时的跳变；
- 支持电脑键盘、鼠标点击 / 滑动和外接 MIDI 键盘演奏。

### 🎛 MIDI 输入 / 输出

- 自动扫描 MIDI 输入设备和输出设备；
- 支持切换输入设备，连接外部 MIDI 键盘进行演奏；
- 支持软件内置音源或外部 MIDI 输出设备；
- 支持延音踏板、柔音踏板、持音踏板等常见控制消息；
- 提供一键 All Notes Off，避免卡音或残留高亮。

### 🎶 SF2 音源管理

- 内置 Upright Piano KW 默认钢琴音源，可开箱即用；
- 支持导入 `.sf2` SoundFont 音源；
- 支持切换、重载、移除和恢复默认音源；
- 音量、采样率、缓冲等音频参数可在设置中心统一管理。

### 🎼 MIDI 播放预览

- 支持导入 MIDI 文件并解析曲目信息、音符、轨道和速度；
- 支持播放、暂停、停止、拖动进度和变速播放；
- 播放／跟弹支持空格开始、暂停和继续，编辑控件或打开面板时不会误触；
- 顶部紧凑控制区整合曲库、左右手、速度和循环，拖动进度时实时预览瀑布位置；
- 播放／练习立即开始音符下落，约 5 秒到达琴键，声音与落键同步；
- 速度按钮显示百分比，点击后使用 Naive UI 滑块调整，范围为 25%–500%；
- 播放时键盘会同步高亮当前音符；
- 同音连续触发时逐次从底色重新亮起，区分长按和重弹；白键底边采用直角；
- 曲目音符向下落至琴键，播放、暂停、变速、跳转与循环同步更新瀑布流；
- 支持区间锚点，可只播放选中的练习范围；
- 循环按钮点击切换，亮起为开启、变淡为关闭；
- A–B 选区采用细边界与灰色范围带，瀑布横向分割线使用 MIDI 真实小节位置；
- MIDI 目录保存系统绝对路径，重新打开软件后可以继续加载历史曲目；
- 重复路径不会重复导入，路径失效时会提示用户清理记录。

### 🧩 跟弹练习模式

- 在主窗口切换 MIDI 播放 / 跟弹练习，浮动曲库选曲或导入后手动开始；
- 自由／播放／练习使用分段按钮切换，主菜单也可打开居中曲库模态框；
- 点击左右手图标切换练习声部，两个点亮为双手、一个点亮为单手；
- 支持根据轨道和音高推断左右手声部；
- 跟弹时练习声部静音，非练习声部可自动伴奏；
- 当前需要按下的音在琴键上显示圆点；和弦逐音按对后，相应圆点立即消失；
- 用户按对当前步骤后自动进入下一步；
- 短时间内接近的琶音 / 和弦会合并显示，减少“一个音一个音跳”的割裂感。

### ⏺ 自由演奏录制

- 在完整瀑布流的自由演奏中开始、停止录制；切换简单模式前停止录制并保留草稿；
- 记录真实音符、力度与踏板事件，支持草稿试听、命名、保存 `.mid` 并加入曲库；
- 定期备份录制草稿，正常退出前检查持久化，保存取消或失败时保留草稿；
- 本分支处于 2.0 开发阶段，正式版本标识和安装包在发布时统一。

### 🎨 外观与主题

- 支持自定义主题颜色；
- 支持白键、黑键、左右手、踏板等不同状态的颜色配置；
- 提供 16 组预设，分为清晰练习、柔和耐看、演奏展示与经典质感；原有 7 组同步优化；
- 外观设置实时预览左右手音条、真实琴键与三种踏板颜色，支持搜索预设；
- 颜色细调默认折叠，展开后按左右手和踏板分组；预览顶部集中显示左右手与踏板图例；
- 根据实际颜色识别当前方案，手动调色后显示为自定义配色；
- 激活琴键的标签按底色选择黑字或白字，界面背景保持中性灰；
- 设置中心采用独立窗口，减少主界面占用。

### 🪟 多窗口同步

- 主钢琴窗口与设置中心窗口互相独立；MIDI 播放 / 练习已整合到主窗口；
- 后端通过 Wails Event 推送设备、按键、播放状态；
- 所有窗口通过 Go 后端的 Wails 事件同步状态；
- 播放高亮、跟弹提示、错键提示和清理状态可以跨窗口同步。

## 🧑‍💻 从源码运行

### 环境要求

- Go 1.26.5+
- Node.js 和 npm（满足当前 Vite 的运行要求）
- 与 `go.mod` 对应版本兼容的 Wails 3 CLI
- 支持 MIDI 的系统环境

### 克隆项目

```bash
git clone https://github.com/Peiratooo/Peirato-s-Piano-Keyboard.git
cd Peirato-s-Piano-Keyboard
```

### 安装前端依赖

```bash
cd frontend
npm ci
cd ..
```

### 同步 Go 依赖

```bash
go mod tidy
```

### 开发模式

```bash
wails3 dev
```

或使用项目任务：

```bash
wails3 task dev
```

### 通过 Wails3 Manager 打包

1. 在 Wails3 Manager 中导入项目根目录，版本信息来自 `build/config.yml`，当前为 `1.3.0`。
2. 构建配置使用 `Taskfile.yml` 的 `release` 任务，应用名 `pp_keyboard`，开启生产构建和 CGO。
3. 启动程序使用默认主程序入口；Windows 为 `bin/pp_keyboard.exe`，macOS 为应用包，不再使用独立启动器。
4. 在 Manager 中执行构建与打包，安装包输出到 `builder/release/`。

仓库保留 `builder/packaging.json` 作为当前 Windows Manager 配置，路径均相对于项目。Windows 附加资源为 `bin/updater.exe` 和三个运行库 DLL；`release` 任务会从仓库资源复制这些文件。安装脚本由 Manager 生成到 `builder/windows/inno.iss`。

macOS 在原生环境中使用 Manager 打包时，将附加资源列表中的 Windows updater 和 DLL 移除，保留默认应用包入口。Manager 使用项目的 `darwin:create:app:bundle` 任务组装应用，通用 updater 会复制到 `Contents/MacOS/updater`，随后签名。

只检查构建、不生成安装包时，可以运行与 Manager 相同的任务：

```bash
wails3 task release
```

主程序与运行文件输出到 `bin/`。Windows 手工 Inno、NSIS/MSIX 和 Linux AppImage/发行包脚本已移除，安装包统一由 Manager 管理。

## 🕹 使用说明

### 1. 使用电脑键盘演奏

打开软件后，可以直接按下电脑键盘中映射到钢琴音符的按键。按下时对应琴键会亮起，松开后恢复。

### 2. 使用 MIDI 键盘演奏

进入设置中心，选择 MIDI 输入设备。连接成功后，外部 MIDI 键盘的 Note On / Note Off 会同步触发软件音源和前端高亮。

### 3. 切换输出方式

在设置中心选择输出目标：

- 无：只显示按键，不发声；
- 软件音源：使用内置或自定义 SF2 音源发声；
- 外部 MIDI 输出：将演奏消息发送到外部 MIDI 设备或虚拟端口。

### 4. 管理音源

音源管理页面会固定显示内置 Upright Piano KW，也可以导入 `.sf2` 文件并切换使用。自定义音源加载失败时，软件会回退到内置音源并继续运行。

### 5. MIDI 播放 / 跟弹

打开 MIDI 播放 / 练习窗口后：

1. 导入一个 MIDI 文件；
2. 在左侧目录选择曲目；
3. 使用播放控制区预览 MIDI；
4. 调整左右锚点选择练习区间；
5. 切换到跟弹模式；
6. 选择左手、右手或双手练习；
7. 根据键盘提示按下对应音符，完成当前步骤后自动继续。

## 🛠 常见问题

### MIDI 设备没有出现

可以尝试：

1. 重新插拔 MIDI 设备；
2. 确认设备没有被其他软件独占；
3. 在设置中心重新选择输入设备；
4. 重启软件后再次检查设备列表。

### 软件没有声音

可以检查：

1. 输出目标是否选择了「软件音源」；
2. 内置或当前自定义 SF2 音源是否加载成功；
3. 系统音量和应用音量是否被静音；
4. 如果使用外部 MIDI 输出，确认外部设备或虚拟端口是否正常发声。

### 播放后出现卡音

可以点击停止或 All Notes Off。软件会向内置音源、外部 MIDI 输出和前端键盘状态同时发送清理指令。
