## 内置音源

`soundfont/UprightPianoKW.sf2` 的 INFO 元数据标识为 Upright piano KW (small, bright)，并指向 [FreePats Upright Piano KW](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html#UprightKW)。来源页以 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 发布；录制与处理署名 Gonzalo、Roberto，采样钢琴由 Inma Martínez de Miguel 提供。音源不适用本项目代码的 Apache-2.0 许可证。

根目录三个 DLL 与 MinGW-Builds GCC 14.2.0 / mingw-w64 runtime v12 本机发行版中的文件 SHA-256 完全一致。它们由现有构建任务引用，保留在原位置。

- `libgcc_s_seh-1.dll`、`libstdc++-6.dll`：GCC GPLv3 与 GCC Runtime Library Exception 3.1；版权归 Free Software Foundation 及上游贡献者。
- `libwinpthread-1.dll`：mingw-w64 winpthreads 的许可声明见本文件末尾。
- [GCC 14.2.0 源码](https://ftp.gnu.org/gnu/gcc/gcc-14.2.0/)、[mingw-w64 v12 源码](https://github.com/mingw-w64/mingw-w64/tree/v12.0.0)、[MinGW-Builds 构建项目](https://github.com/niXman/mingw-builds)。分发运行库时需保留其许可及适用的源码获取信息。
