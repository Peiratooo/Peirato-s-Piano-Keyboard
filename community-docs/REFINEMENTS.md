# 界面与练习细节修整（2026-11-02）

## 本轮变更

- 黑白键按下和延音时，移除遮住键面底部的固定阴影，高亮覆盖完整键面。左手延音使用左手配色；手别保留到实际发声结束。
- 设置侧栏统一使用 Phosphor SVG 图标。清理触键力度公式、后端扫描等面向实现的描述，保留用户需要的操作提示。
- 菜单只保留一个“练习”入口；同一页提供选曲、继续练习及练习记录。桌面工坊改为独立窗口，界面使用钢琴原有深灰与主题色。侧栏收拢为工坊、练习、我的；上传和收藏位于“我的”。
- 顶部和底部均提供“返回钢琴”。桌面返回会聚焦原钢琴窗口；选择曲目进入原曲库。多窗口使用同一个 Go 播放器，选曲、播放模式和进度保持同步。
- 工坊普通试听使用 play 模式；从跟弹切入工坊时结束等待按键状态。保留定位后的播放位置，准备播放时显示倒计时。暂停请求期间播放按钮保持外观，不再因 disabled 透明度闪烁。
- 工坊进度滑杆点击或拖动后提交定位，不再只留下未提交的拖动预览而锁住进度显示。
- 跟弹提前识别窗口由 80ms 放宽至 300ms。网页在音符到达前也接受正确音符，到达后继续；已按下的音不要求重复按。
- 无需登录即可记录所有本地 MIDI 的练习次数、时长、最近时间和模式。桌面保存到 Application Support 下 practice-history.json（0600），网页保存到本机浏览器。练习页默认本机记录；登录后可切换同步记录。
- 桌面退出时停止播放器并写入最后一段本地记录；开始 MIDI 播放前沿用录制草稿备份。修正桌面头像使用的 API 地址映射。

## 实际验证

1. 桌面导入 hand-velocity MIDI，验证左右手黑白键的完整高亮；跟弹中开启软件延音，点击并松开 C5 后保持左手的浅珊瑚色。截图 refinement-keys-native.jpg、refinement-left-sustain-native.jpg。
2. 首音在 1000ms 的临时片段定位到 747ms，启动并按住一次 C5，进度越过首音到 1819ms，无需重新按键。
3. 从等待按键的跟弹进入工坊，普通试听开始后进度自动前进；桌面工坊与主窗口分别观察到 0:01 和 0:09。重启后打开工坊，播放按钮也能直接开始普通试听，准备阶段显示倒计时。
4. 网页从跟弹进入工坊后不再等待按键，进度到 0:14。点击滑杆定位到 0:09 后开始播放，继续使用当前位置。
5. 未登录且 API 未启动时，桌面与网页均保存本机记录。桌面重启、网页重载后记录仍在，并可继续练习。两首桌面临时样本及其对应本机记录已按 ID 清理；网页保留内置小星星的真实验收练习记录，便于检查新功能。
6. 桌面独立窗口的返回钢琴、选曲返回曲库、侧栏及 SVG 设置图标通过；网页“我的”在游客状态显示登录入口。手机 390×844、844×390 均无横向溢出；横屏收拢侧栏、减少次要统计占位，直接显示继续练习按钮。
7. 最终网页新加载的练习页 error/warn 日志为空。API 启动后 health 成功，工坊展示真实空状态。没有创建或更改远端数据库中的业务数据。
